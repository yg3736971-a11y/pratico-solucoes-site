# Prático Soluções — site público

Site estático da Prático Soluções, sem inteligência artificial e sem credenciais.

## Recursos

- apresentação dos serviços;
- atendimento para residências, condomínios e empresas;
- cobertura da região central de São Paulo;
- assistente guiado que organiza o pedido no navegador;
- envio final pelo WhatsApp `55 11 96526-7558`;
- layout responsivo e acessível;
- publicação automática no GitHub Pages.

## Executar localmente

```bash
python3 -m http.server 4173
```

Abra `http://127.0.0.1:4173`.

## Segurança e privacidade

O assistente não usa IA, backend, banco ou rastreamento. As respostas ficam no navegador e só saem do dispositivo quando a pessoa decide abrir o WhatsApp.

Preço, prazo, cobertura e agenda dependem da confirmação humana da Prático Soluções.
